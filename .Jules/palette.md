## 2024-05-18 - [Modal Close Button Accessibility]
**Learning:** In this application, modal close elements are often implemented as `<span class="modal-close">` rather than native `<button>` tags. While adding `aria-label` is necessary, screen readers and keyboard users also need `role="button"` and `tabindex="0"` on non-native interactive elements to focus and interact with them properly. Modifying the tag itself to `<button>` can sometimes break existing CSS styling bound specifically to `span`, so adding proper ARIA roles and tabindex to the `span` is a safer bet for accessibility improvements without introducing visual regressions.
**Action:** When improving accessibility for custom interactive elements (like `<span>` or `<div>` acting as buttons), always check if they are keyboard-focusable (`tabindex="0"`) and semantically identifiable (`role="button"`) in addition to having an accessible name (`aria-label`).
